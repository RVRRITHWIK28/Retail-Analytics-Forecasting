# Retail Analytics & Revenue Forecasting

## Project Overview

- Exploratory Data Analysis (EDA)
- SQL Business Analytics
- Star Schema Data Modeling
- Revenue Forecasting using SARIMA
- Interactive Power BI Dashboard

## Tech Stack

- Pandas
- MySQL
- Power BI
- Statsmodels (SARIMA)
